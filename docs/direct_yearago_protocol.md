# DIRECT_YEARAGO — preregistration V1

This protocol is committed before candidate effects are calculated. User approval
is the attached DIRECT_YEARAGO task; no additional approval is inferred.

## Immutable design

- Baseline: original DIRECT30x2, expanded replay commit
  `34bdc3b703c45326f3c638814ad18595c8124e83`.
- Diagnostic reference: `8908e71bc45bc0891b84fca5c4103058fc5ad984`.
- Reusable audit/scoring helpers: CONTEXT90 commit
  `95d6b08702e8e3e66ede6ae3aa361578f2e2a98b`.
  None of its six extra model features enter this candidate.
- Only archived local input is allowed. Zero database queries, no production
  writes, no new shadow run, no deployment. Archives remain byte-identical.
- Twenty mature issues, January 2025–August 2026; full core 2,820 object-issues,
  original DIRECT output scope 2,579. September/October stay NOT_MATURED.
- Issue S, cutoff C=S−2; targets S+1..30 and S+31..60; total is their sum.
  Each training row r uses its own c=r−2. Segment labels end at or before C.
- Original training keys, labels, weights (implicit uniform), old feature values,
  qualifications, model parameters, seed and nonnegative/unrounded output are
  unchanged. M2 never reads M1 predictions or later M1 actuals.
- All periods are repeatedly studied reconstructed development validation, not
  independent OOS or proven historical point-in-time data.

## Sole feature increment

Move the issue anchor r to the previous calendar year's same month/day, with
February 29 alone falling back to February 28. Then construct:

- c_ly=r_ly−2; I_ly=c_ly−27..c_ly (28 days);
- Y1_ly=r_ly+1..r_ly+30; Y2_ly=r_ly+31..r_ly+60 (30 days each).

All annual dates must be at or before that row's own c. Save exact window bounds.
The new numerical fields are `ly_input_mean28`, `ly_target_mean30`,
`ly_scale_contrast=(m_now−m_ly_input)/(m_now+m_ly_input)`, and
`ly_shape_contrast=(m_ly_target−m_ly_input)/(m_ly_target+m_ly_input)`.
The temporary m_now is not an extra model field and does not overwrite old means.
Complete explicit zero/zero gives zero; missing, invalid, NULL or unsafe mapping
gives NaN for every affected calculation. No epsilon, imputation or ratio clipping.

The new flags are `ly_input_complete`, `ly_target_complete`, and
`ly_positive_observed_before_input_start`. Following the user's precise definition,
the last flag is **inclusive of I_ly's start date**: any valid positive sale on or
before that date, visible by c. Zero means not observed in this archive, not no
listing, no trading, or a proven launch date.

Preserve the five diagnostic states: both windows complete with earlier positive;
both complete without such observation; one complete; both missing; unsafe source
or mapping. Historical operating comparability remains UNKNOWN in every state.

## Pre-effect fit support and budget

For each issue/segment, support rows have both annual windows complete and the
positive-observation flag equal to one. Run only when they span at least 30
distinct simulated issue dates, at least 10 distinct shop×SPUs, and their four
annual numerical features are not all constant. This is a technical screen, not
independent seasonal evidence.

Fit passing units on the **whole original training matrix**, retaining annual
NaNs. Failing units are never fitted and receive
`BASELINE_REUSED_INSUFFICIENT_ANNUAL_SUPPORT`. The comparison stream may use the
exact original same-key/segment prediction, with original file hash. True annual
prediction remains NULL there. Original missing predictions remain missing.
Save annual_model_prediction, comparison_prediction, prediction_origin and reason.

Maximum 40 formal fits, one per passing unit, no parameter search or old-model
refits. Save models/checkpoints; an interrupted fit without a checkpoint is not
silently retried. Synthetic test fits are separately labelled, not business fits.
Freeze all support results, parameter and input hashes before any candidate fit.

## Evaluation fixed before effects

Report all three target windows in (A) full core, (B) original complete DIRECT
scope, (C) objects with both segments actually generated by annual models, and
(D) annual reference states. Recompute DIRECT/F28 on each exact subset.
CONTEXT90 is auxiliary archived output only.

Report WAPE, Bias, over/under units, positive-truth ±20% hits, explicit-zero
absolute error, joint three-window hits counted once, their actual-sales weight,
gained/lost/retained hits, unknown and missing outputs. Reuse the original
CONTEXT90 pre-issue-declining membership, not a new definition.

Five unrounded research screens, all on the original paired scope:
1. 60-day WAPE strictly below DIRECT;
2. joint hit count strictly higher;
3. joint-hit actual sales share not lower;
4. original declining-group 60-day overprediction rate not higher;
5. original output and core coverage not lower.

No new significance or breadth thresholds are introduced. Report declining-group
and annual-support breadth, temporal overlap, repeated development and missing
operating-history limits. Business evidence stays PARTIAL; no automatic model
selection even if all numerical screens pass.

Slice by issue/year, shop, original maturity, current descriptive category/season,
annual status, and declining group. Current labels are evaluation-only.
Inspect JQ-US bodysuits/tank tops, T-shirts/autumn-winter and missing-history
groups; show concentration by product and November 2025, not a revised gate.

## Integrity tests and deliverables

Test annual/leap/cross-year windows; row-specific cutoffs; old train equality;
zero/NULL/missing/source semantics; contrast bounds; shop/product isolation;
future perturbations; skipped-fit proof and exact fallback; M2 independence;
raw daily truth resums; joint denominators; all archive hashes unchanged.

New exclusive local output directory holds support/window audits, checkpoints,
origin-labelled predictions, scoring/migration tables, independent validation and
the Markdown report. Publish only source, tests and sanitized specifications on
the separate GitHub branch, never business input/results/models/credentials.
Stop after the single bounded experiment.
