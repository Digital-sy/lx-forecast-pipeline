|effective_from/to|映射、品类、季节或经营状态的生效区间；没有历史证据则为UNKNOWN，不把当前状态投射到历史|
|training cutoff|销量特征严格早于签发业务月首日；训练目标月严格早于截点；训练数据真实获取时间不得晚于本次决策|

业务时区Asia/Shanghai。来源级acquired_at也必须逐个核对decision_at；现有验证器目前只比较manifest级时间，需补来源级检查，不能只凭顶层时间通过。

当前品类/季节可以证明“本次决策时已知”，不自动证明历史训练时曾可用。保留此限制；不以未来目标真值反推元数据选择。

未知时间仍为null/UNKNOWN：旧校验器要求business_asof可解析，当前不支持该项为空；应显式报未就绪或在兼容修订中保留未知并禁止点时通过，绝不造时间满足校验。acquired_at若无法记录，不能认证为原始捕获。任何来源同步阈值先由业务确认，本文不新增正式阈值。

输出两个不同结论：replay_ready仅指输入可离线复算；前瞻证据合格还需外部收据、来源状态和真实时间核验。UNKNOWN可保留观察证据，但不能静默通过“点时已验证”。

## 7. 完整对象与状态守恒

先冻结观察全集及其来源范围，再生成模型输出。至少包含获批店铺完整历史的SKU/SPU；若已治理商品注册表纳入范围，则合并其对象并保留无历史者。未能证明覆盖商品注册全集时，明确是“授权来源观察全集”，不是所有在售商品。

原始SKU/SPU缺失、冲突或无法归店的行以稳定原始行引用进入隔离台账，不编造SPU或补0。有效对象按shop×SPU×target_month×horizon保存：

- qualification：ESTABLISHED / 其他明确无资格类别 / UNKNOWN；
- input_state：COMPLETE / MISSING_INPUT / MAPPING_CONFLICT等，带原因；
- 各模型output_state：OUTPUT_POSITIVE / OUTPUT_ZERO / INELIGIBLE / MISSING_INPUT / MISSING_OUTPUT / FAILED。

三种状态分别记录，不用单一“成功”掩盖资格或来源缺口。每个期望对象每个模型恰好一个输出状态；失败对象数量加成功/缺失/无资格数量必须对回全集。覆盖同时报告全部观察对象、已确认资格对象、可接受输入对象与两轨共同评分对象；未知资格单列，不能出分母后消失。
