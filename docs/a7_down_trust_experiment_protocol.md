# A7 DOWN 历史可比性：候选实验预登记草案

状态：只定义下一轮离线实验及归档要求；尚未修改候选、选择系数或执行实验。模型、数据库、采购、BI、调度均不受影响。

## 1. 范围与先后顺序

优先方向为 A：**历史季节候选在 DOWN 分支被全替换采用前，先识别历史经营条件是否可比**。识别 UNKNOWN 不等于认定应提高预测；A3 也不是实销真值。原冻结 A16、生产 V4 原路径和上月销量延续始终为对照。

四个已观察对象属于探索样本，不能成为挑选系数、设定业务特例或独立 OOS 的依据。不把其参考低销量直接称淡季。类目/季节当前标签不得冒充历史标签。

本文件冻结研究问题、候选结构和评价方案，而非冻结新模型。将来执行前必须另行预登记有限参数网格、训练/开发/测试月份、主指标和业务容忍边界，并取得授权；不能在已看到测试结果后更改它们再声称同一测试集独立。

## 2. 信任状态及资料要求

每个历史参考窗单独标记：

- COMPARABLE：有效日期明确的映射、在售状态、可售供给及价格/活动范围能支持可比；需来源级证据，不只看销量。
- NON_COMPARABLE：有记录证明供给中断、经营范围/变体结构或活动制度显著变化。
- UNKNOWN：关键证据未留存、含缺记录、获取时间不清或字段历史语义未验证。

“日表有库存字段”“一行库存为0”“当前 inactive”均不足以完成上述判定。库存流水是事件，不天然等于可售余额；还需期初余额、事件完整性、库位/状态及有效映射才能重建。

销量状态保留 OBSERVED_VALUE、OBSERVED_ZERO、UNKNOWN。历史三个月只要缺记录，就不得将内部默认0描述为观测零。新旧SKU集合变化只是可比性警示，不能自动推断变体真实上线、停产或映射漂移。

## 3. 四个单因素方向

|方向|要解决的问题|预定离线比较|主要反向风险|
|---|---|---|---|
|A DOWN季节可信度（先做）|参考低谷可能混入经营变化或缺输入，而当前DOWN缺少与UP对称的信任校验|A0保持冻结；A1仅增加可比性状态不改数值；A2将既有混合式 `(1-g)*A3 + g*季节候选` 的资格与证据状态关联。g的有限集合及未知策略只可在训练/开发阶段预登记选择，不以四款结果指定值|真实季节性下降和持续衰退被阻拦，保留过高A3、增加库存|
|B 近期恢复|近月连续恢复与三个月同比偏低可能并存|先做恢复持续性、同SKU可比销售、活动依赖、供给恢复分层；再与单纯最近月延续比较。门槛仅训练选择，缺证据不认定持续恢复|促销脉冲、补货集中释放或短期反弹被外推|
|C 同比封顶与经营阶段|固定封顶不能区分同SKU自然增长与新增SKU贡献|拆同SKU可比增长/新增SKU贡献/退出SKU贡献，比较原封顶与训练期定义的分层封顶。不可直接取消上限|小分母、变体重复映射和扩款高峰造成上行爆炸|
|D 上下行对称校验|UP有历史/类目/集中度保护，DOWN的参考可信度校验较弱|在A完成后单独消融：缺失、参考异常、类目广度和集中度各自影响；不直接把UP规则镜像复制到DOWN|广泛衰退被误当异常、类目聚合掩盖单款真实退出|

A2只是候选结构，不决定 UNKNOWN 一律回到 A3，也不规定衰退款必须抬高。不以“减少下调件数”为成功目标。

## 4. 样本、日期与防泄漏

1. 维持完整店铺×SPU输入及类目支持群体，计算后分层汇报；禁止先裁四款或只保留改善款。
2. 预测截点只允许此前完整自然月；训练目标月、拟合校准标签必须早于截点且有可获得性证据。业务时间和实际获取时间分开检查。
3. 已用于模型开发/选参/人工探索的月份全部登记为历史回放或开发验证；未能恢复历史可获得性时不得称独立 OOS。
4. 冬季/跨年历史窗若被读过或参与研究，只做时间外推压力测试，不能自动获得独立性。独立测试须有封存的未见目标、冻结选择过程和真实获取凭证；否则以后经批准进行前瞻观察。
5. 固定相同对象、截点、Horizon及实销真值；同样本指标与完整资格全集覆盖率双报。未知实销不补0，缺预测不从分母静默删除，无资格单列。
6. 当日源与月源不一致，先报告差异及语义，锁定评价真值版本后再运行。回放可以使用今天拿到的历史记录，但须标记可获得性限制。

## 5. 预定指标、保护组与放行门禁

对总体、H2/H3、店铺、成熟度、季节/品类、销量层、信任状态及近期恢复/衰退组分别报告：

- WAPE=`sum(abs(p-y))/sum(y)`；Bias=`sum(p-y)/sum(y)`；分母0时不可计算。
- 低估件数=`sum(max(y-p,0))`；高估件数=`sum(max(p-y,0))`；分别除相同实销分母，不能以净Bias抵消。
- ±30%命中率：正实销样本单列；实销0样本单列绝对误差，不除零。
- 资格对象数、输出覆盖率、实销已知比例、三模型共同可比比例；未预测、缺实销、无资格分别计数。
- 改善/退化SPU数及实销权重、Top误差贡献、重点对象变化；按SPU分组的不确定性区间，避免把同款多月当独立样本。

保护组预先固定：持续下滑、去年冬季低谷重复出现、长期低量/停售证据明确、活动回落、变体缩减对象；其标签必须由截点前资料给出，不得依测试目标月实际值反向选模型。

技术门禁：源码/参数/输入/输出哈希全部对得上；无时间泄漏；无业务键重复或跨店合并；完整上下文；缺失保留；失败可追溯。业务门禁：总体改善不能以真实衰退组高估显著恶化换取；具体容忍阈值由业务负责人在实验前确认，本文件不冒充已经批准的正式规则。

停机条件：输入或真值不一致、资格变化解释不清、无法恢复训练可获得性、保护组样本不足、不可比组改善但已确认可比组明显退化。保留V4和冻结A16，不自动部署。
