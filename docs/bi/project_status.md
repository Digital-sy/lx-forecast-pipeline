## 不可混淆的业务口径

- 推荐下单量为主，预测销量为辅。已计算的建议量不在BI中再次扣库存。
- 展示库存包含FBA可售、本地可用量、FBA在途，不包含本地待到货。“订单未交付”与库存/在途未经验证不得相加。
- 近七日日均允许截至最新已核验完整业务日，必须标明截止日；缺记录不自动补零。
- 默认跟单按用户确认采用采购员。按同店铺、同SPU最近正常有效采购归属；排除返修、尾数、取消、作废、未生效及用途不明订单。多工厂/多人冲突留待分配，不复制需求。实际订单数量统计不因此删除特殊订单。
- 面料仅纳入《定制面料参数》中已确认的面料；以“米数每条”为换算标准，其他重量参数仅参考。旧A2023和新B2024颜色映射到同一实物池时，共用库存只扣一次。
- 面料用量、预计需补、最终采购数量是不同概念。条数原值可以有小数；显示整数不代表执行整条采购。
- 业务日期、源同步时间、BI抽取时间、计算批次及发布时间分别记录；不能用抽取时间冒充业务更新时间。
