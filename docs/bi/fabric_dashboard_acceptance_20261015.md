## 单位和显示规则

1. 权威参数为《定制面料参数》的“米数每条”。按面料逐行进行米数/换算参数，再汇总，禁止以平均参数转换总米数。
2. 参数缺失、非正数或不唯一时不臆造条数；保留未知并核对。用量、净量仍保存原始数值精度，不因展示取整改变库存扣减。
3. 数量表与主要KPI：未知为“—”；真实零为“0”；`0 < x < 1`为“<1”；其他数值采用整数千位分隔显示。先按原始值聚合，再格式化。
4. 折线保持数值类型，提示配置4位小数；轴可用小数表示不足一条，不将微小正需求误显示为零。
5. 隐藏曲线只针对三个月完整且原始值全部为零的系列；显示四舍五入为0不代表实际为0，未知也不算零。
6. 主界面使用“预计需补”，不是可直接执行的采购数量。采购单位1条、通常同色4条起采仅登记待办，尚未纳入运算。
